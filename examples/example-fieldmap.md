# 示例：字段图（三档，第 6 节）

对象：一个「只从给定文档回答、每句话必须带可核对引用」的问答 agent。字段图回答的是：它在动哪些东西、状态怎么变、哪里会错、读者不看代码能不能看出来。

## 字段图

### 关键变量 / 状态
- `corpus`：允许引用的文档集合（真值源）
- `retrieved_blocks`：本轮实际检索到并发给模型的片段（带编号）
- `claims`：模型输出中拆出的原子主张
- `citation_ok[claim]`：该主张的引用是否逐字命中 `retrieved_blocks`
- `withheld`：被闸门拦下的主张及原因

### 转换（状态如何变、谁触发）
- 问题 → 检索 → `retrieved_blocks`（召回不足时这里就已经错了，但表现为"找不到"）
- 模型输出 → 拆句 → `claims`
- 每条 `claim` → 引用核对 → 进正文 或 进 `withheld`
- `withheld` 非空 → 单独列出；正文为空 → 固定回复「在给定资料中找不到」

### 可能的失败点（在哪里、怎么表现、怎么发现）
- 真引用假主张：引用逐字命中，但主张说的不是引用的意思——格式检查抓不到，只有独立的蕴含校验能抓；发现方式：在测试集里植入已知的错配对
- 召回缺失：答案在文档里但没检出 → 表现为「找不到」（方向对、结果仍错）；发现方式：可回答集上的拒答率
- 退化解：全部标「未经验证」或全部拒答 → 通过所有幻觉检查，但没用；发现方式：拒答率上限

### 关键假设
- 文档本身是对的（引用的垃圾仍是垃圾）
- 模型会给每条事实句附引用；若经常不附，闸门会过度拦截——修的是提示词，不是闸门

### Sampling / Variance 顾虑
- 10 次演示没出错对「永不」的证据力接近零；幻觉是尾部事件，必须在 n ≥ 200 的集合上跑 ≥5 轮并报区间

### 此方案明确不处理的内容
- 没有真值源的开放域问答（那里「幻觉率」没有裁判，只能谈校准度）
- 顺序与强调造成的误导（句级闸门看不见）
