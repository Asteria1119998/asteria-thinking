# 示例片段：意图 / 规格 / 差距（三档中的第 2–4 节）

用户请求：「做一个有帮助但永不幻觉的 agent。」此处只展示三节的写法，不含横幅与其余章节，不用于校验。

## 意图
用户希望 agent 说出口的事实性主张可以不经逐条复核就敢用；不知道的时候会说不知道；同时仍然在做事（拒答率不能高到等于没有它）。

## 规格
- 每条事实性主张必须附来源指针，或显式标「未经验证」。
- 在允许的工具／资料内找不到支持时，必须说找不到依据，不得用通顺度补位。
- 引用的文档、段落、接口必须真实存在（程序可查）。
- 在可回答集上，拒答率与「未经验证」占比有上限（否则退化解是什么都不断言）。

## 差距
意图是「永不幻觉」，规格只能强制「必须标记或拒绝」。差距在于：模型仍可能生成一条看似合理的主张，然后**没标**——标记这一步本身不可靠。所以缓解不是更严的提示词，而是生成模型之外的校验器或二次验证；并且「永不」只能落成「机械可查的那一类为零 ＋ 语义类有上界」，这一条差距必须告诉用户。
