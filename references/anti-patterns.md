# 反模式（Anti-Patterns）

| 反模式 | 为何失败 | 必需修正 |
|--------|----------|----------|
| 单样本能力宣称 | 忽略 variance | 显式处理 sampling：写 n、给重跑计划、报区间 |
| 差距之前就给方案 | 隐藏意图与指令的不匹配 | 强制先 意图 → 规格 → 差距 |
| 没有字段图就写代码（三档） | 读者看不到失败点 | 设计 ＋ 字段图在代码之前 |
| 无法测试的建议 | 无法被修正 | 附上假设 ＋ 检验 ＋ 修正；能跑的先跑 |
| 表面分类 | 错过根结构 | 用分类法，并执行主类型的分流动作 |
| 乐观计划 | 假设完美反馈 | 说明反馈质量与修正路径 |
| 档位错配 | 小任务套三档是税（形式合规不换来正确性）；不可逆操作套一档是风险 | 按四轴定档，横幅里声明，用户可一词改档 |
| 对着校验器写字 | 优化了代理指标（标题存在）而不是真实目标（想清楚）——正是 Optimization 型失败 | 写完再跑校验；不先读规则；PASS 后再读一遍自己的差距与失败点 |
| 贴标签不分流 | 分类没有改变任何后续动作 | 主类型 → 额外必做（见分类法） |
